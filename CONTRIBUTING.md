# Contributing to Persian LLM Benchmark

Thank you for your interest in contributing to `persian-llm-benchmark`!

## How to Contribute

1. **Fork & Branch**: Create a new feature branch from `main`.
2. **Add Benchmarks**: Submit new benchmark questions in `data/` adhering to the standard schema (`prompt`, `reference_answer`, `task`, `rationale`).
3. **Run Tests**:
   ```bash
   pytest -v
   ```
4. **Submit PR**: Open a pull request with a concise description of changes.
